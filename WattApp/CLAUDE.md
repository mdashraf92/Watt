@AGENTS.md

## gstack

Use the `/browse` skill from gstack for all web browsing. Never use `mcp__claude-in-chrome__*` tools.

Available gstack skills:
- `/office-hours` — product interrogation and ideation
- `/plan-ceo-review` — strategic challenge and scope review
- `/plan-eng-review` — architecture and design review
- `/plan-design-review` — design review of a plan
- `/design-consultation` — design system and visual identity
- `/design-shotgun` — rapid multi-direction design exploration
- `/design-html` — HTML/CSS design implementation
- `/review` — code review before landing
- `/ship` — create PR and ship
- `/land-and-deploy` — merge + deploy + verify
- `/canary` — post-deploy monitoring
- `/benchmark` — page speed and performance
- `/browse` — open real browser for QA and visual inspection
- `/connect-chrome` — connect to Chrome for authenticated testing
- `/qa` — QA lead: opens real browser, tests and fixes bugs (the QA lead)
- `/qa-only` — report bugs without fixing
- `/design-review` — visual polish audit of live site
- `/setup-browser-cookies` — import cookies for authenticated testing
- `/setup-deploy` — configure deployment
- `/setup-gbrain` — configure GBrain
- `/retro` — weekly retrospective
- `/investigate` — root cause debugging
- `/document-release` — update docs after shipping
- `/document-generate` — write docs from scratch
- `/codex` — second opinion review
- `/cso` — security officer (OWASP + STRIDE)
- `/autoplan` — run all reviews automatically
- `/plan-devex-review` — developer experience review
- `/devex-review` — live DX audit
- `/careful` — safety mode
- `/freeze` / `/unfreeze` — restrict edits to a directory
- `/guard` — guard mode
- `/gstack-upgrade` — upgrade gstack
- `/learn` — show what gstack has learned
